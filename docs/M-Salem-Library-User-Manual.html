1. Overview

M'Salem School Library Management System is a desktop application for managing school library operations. It supports cataloging books, issuing physical books, dispatching digital PDFs, managing borrower directories, tracking overdue books, generating PDF reports, emailing reports, recording financial activity, and auditing security events.

The production app runs locally and stores data on the computer. It automatically starts the backend service when the desktop app opens.

2. User Roles

Admin

Admins can manage books, borrowers, active/archived records, overdue follow-ups, reports, and general statistics.

Superadmin

Superadmins can do everything admins can do, plus manage admin accounts, view security logs, and access the financial vault.

3. Login and Session

Logging In

  1. Open the M'Salem Library desktop app.
  2. Go to the login screen.
  3. Enter the admin email and password.
  4. Click Enter Dashboard.

If the server is still starting, wait a few seconds and retry. If an account is suspended, contact the superadmin.

Session Timeout

The dashboard logs users out after about 5 minutes of inactivity. Mouse movement, typing, clicking, scrolling, and touch activity keep the session alive.

Logging Out

Click Logout to Home at the bottom of the dashboard sidebar.

4. Dashboard

The dashboard is the main navigation center. The sidebar is grouped into Superadmin, Book Management, User Management, and Monitoring. The Overdue Books item displays a badge when books are overdue.

5. Book Management

Add Book Title

Use this page before issuing a book. A title must exist in the catalog before it can be selected in the borrowing form.

  • Physical book: enter title, details, category, fee, and physical quantity, then click Add to Catalog.
  • Digital book: upload a PDF, enter the details and fee, then click Upload Digital Book.

Exact duplicate titles are blocked. Digital books are treated as unlimited stock.

Book Catalog

Use the catalog to search, edit, and delete catalog entries. The page shows category, format, fee, and live stock. Click Edit to change a title, author, category, type, fee, or quantity. Click Delete and enter admin credentials to remove a title.

Borrow Book

  1. Search and select a book title.
  2. Search and select a borrower or enter a new borrower.
  3. Enter or generate a borrower ID.
  4. Select category and sub-category.
  5. Enter contact information.
  6. Set issue date and, for physical books, return date.
  7. Adjust fee if necessary.
  8. Click Confirm Physical Issuance or Dispatch PDF via Email.

Digital books require a valid email address and do not require a return date.

Active Books

This page lists physical books currently out. Use it to search records, mark returns, delete records with admin credentials, export PDF reports, email reports, and filter reports by date range.

To return a book, click Return and confirm. To delete a record, click Delete, enter admin email and password, then confirm.

Archived Books

This page shows returned physical books and dispatched digital books. Search by title, borrower, or borrower ID. Records can be permanently deleted after admin credential confirmation.

6. Overdue Books

The Overdue Books page lists physical books past their expected return date. You can search by title, borrower, or ID; filter by due-date range; export a PDF report; email the full report; send email reminders; and start a phone call when the contact is a phone number.

  1. Open Overdue Books.
  2. Use the search or date filters if needed.
  3. Click PDF to export or Email to email a report.
  4. Click the contact action button to remind an individual borrower.

7. People Management

Students List

Use Students List to bulk import, search, edit, delete, promote, and graduate/archive student records.

  • Bulk Import: paste names separated by lines or commas, choose category and class, then import.
  • Promote: choose from-class and to-class, execute, and confirm.
  • Graduate: choose the final class and confirm archive.

Staff List

Use Staff List to bulk add staff, search the directory, edit names, and delete records.

General Users

Use General Users for community members, parents, alumni, visitors, and other borrowers who are not students or staff. Users can be bulk added by category, searched, edited, or deleted.

8. Statistics

Statistics summarizes library activity, including total transactions, books currently out, digital dispatches, returned/archive records, weekly/monthly/yearly activity, category breakdowns, and superadmin financial totals.

9. Superadmin Features

Admin Management

Superadmins can register new admins, suspend/reactivate admins, delete admin accounts, and review activity logs. The superadmin account cannot be deleted or suspended.

Security Logs

Security Logs shows the latest audit events, including logins, registrations, updates, deletions, book returns, imports, and reminder/report actions. Logs can be searched and refreshed.

Financial Vault

The Financial Vault lists fee records, total revenue, physical revenue, digital revenue, borrower details, book type, date, and issuing admin.

10. Reports and Email

The app can generate PDF reports for active borrowed books and overdue books. It can email active reports, overdue reports, individual reminders, and digital PDF books.

Email actions require valid backend email settings: EMAIL_USER and EMAIL_PASS. Gmail accounts may require an app password.

11. Data Storage

Production database files are stored in:

C:\Users\<YourUser>\AppData\Roaming\msalem-library\database

Uploaded digital PDFs are stored in:

C:\Users\<YourUser>\AppData\Roaming\msalem-library\database\uploads\pdfs

Do not manually edit database files unless a backup exists.

12. Recommended Daily Workflow

  1. Log in.
  2. Check the overdue badge.
  3. Add new catalog titles if needed.
  4. Issue books through Borrow Book.
  5. Mark returns through Active Books.
  6. Follow up overdue books.
  7. Update students, staff, or general users as needed.
  8. Export or email reports.
  9. Log out.

13. Troubleshooting

Login works but actions fail

Log out and log in again. Confirm the latest app version is installed.

Add book fails

Confirm the title is not an exact duplicate. For digital books, confirm the file is a PDF.

Staff or student import fails

Confirm you are logged in, names are separated by lines or commas, and the list has no blank-only rows.

Email does not send

Confirm recipient email is valid and backend email credentials are configured.

PDF does not open

Wait for report generation, try a smaller date range, and confirm a PDF viewer is installed.

Session expired

Log in again. This is expected after inactivity.

14. Good Practices

  • Add catalog titles before issuing books.
  • Use consistent borrower names and IDs.
  • Mark returned books immediately.
  • Export regular reports for record keeping.
  • Restrict superadmin access to trusted users.
  • Back up the database folder regularly.
